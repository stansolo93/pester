# Pricing Model Decision

## Context

Need to set pricing before public launch. Three options considered.

## Options

1. **Flat monthly fee** ($49/mo) — simple, predictable
2. **Usage-based tiers** (Free / Pro $29 / Enterprise custom) — aligns cost with value
3. **Per-seat pricing** ($15/user/mo) — penalizes growth

## Decision

Going with **Option 2: Usage-based tiers**. Free tier gets 100 API calls/month, Pro gets 10K, Enterprise is custom.

## Rationale

- Free tier drives adoption and word-of-mouth
- Usage-based scales naturally with customer growth
- Enterprise tier opens door for sales conversations
- [[alice]] and [[carol]] both preferred this approach
